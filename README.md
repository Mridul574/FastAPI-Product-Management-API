# FastAPI Product Management API 🚀

A backend REST API built using Python, FastAPI, and PostgreSQL to manage product data.

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Psycopg
- Pydantic
- Alembic
- JWT Authentication

## ✨ Project Overview

This project focuses on building a structured backend application using FastAPI and PostgreSQL.

It includes database integration, ORM-based models, API development, database migrations, and JWT-related security utilities.

## 📂 Project Structure

- `main.py` – Main FastAPI application
- `database.py` – Database connection
- `models.py` – SQLAlchemy database models
- `security.py` – Security and JWT utilities
- `alembic/` – Database migration management

## 🎯 Learning Objectives

- Building REST APIs with FastAPI
- Connecting PostgreSQL with SQLAlchemy
- Working with database models
- Managing database migrations
- Understanding JWT authentication
